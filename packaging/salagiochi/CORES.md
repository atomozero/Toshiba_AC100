# The libretro cores of SalaGiochi

SalaGiochi itself is under the MIT license. The emulators it starts are
libretro cores, built for the Toshiba AC100 (ARMv7-A, VFPv3-D16, no NEON)
from the projects below, each under its own license. No games are included.

| Core | Systems | Project | License |
|---|---|---|---|
| fceumm | NES, Famicom Disk System | https://github.com/libretro/libretro-fceumm | GPL v2 |
| gambatte | Game Boy, Game Boy Color | https://github.com/libretro/gambatte-libretro | GPL v2 |
| gpsp | Game Boy Advance | https://github.com/libretro/gpsp | GPL v2 |
| picodrive | Mega Drive, Master System, Game Gear | https://github.com/libretro/picodrive | PicoDrive license (free, non-commercial) |
| snes9x2005 | Super Nintendo | https://github.com/libretro/snes9x2005 | Snes9x license (free, non-commercial) |
| mame2003_plus | arcade | https://github.com/libretro/mame2003-plus-libretro | MAME license (free, non-commercial) |
| vecx | Vectrex | https://github.com/libretro/libretro-vecx | GPL v3 |
| pcsx_rearmed | PlayStation | https://github.com/libretro/pcsx_rearmed | GPL v2 |
| desmume2015 | Nintendo DS | https://github.com/libretro/desmume2015 | GPL v2 |
| tic80 | TIC-80 | https://github.com/nesbox/TIC-80 | MIT |

The exact sources the cores were built from, with the changes made for Haiku,
are in the `salagiochi-cores-src` archive of the same release.
